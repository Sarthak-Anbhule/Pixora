# Pixora — Feed System Module (C++)

**Author:** Lolita Gudme
**Language:** C++
**Project:** Pixora (Pinterest Clone) — Data Structures Activity

## Files
- `MyQueue.h` — Custom FIFO Queue (linked list)
- `MyHashMap.h` — Custom Hash Map (chaining + djb2)
- `FeedSystem.h` / `FeedSystem.cpp` — Feed logic
- `main.cpp` — Demo runner

## How to run in Dev-C++
1. Create a Console Application project.
2. Add `main.cpp` and `FeedSystem.cpp` to project.
3. Press F11.
