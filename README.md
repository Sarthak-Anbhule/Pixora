# Pixora — Chat & Notification Module

## Author
Tejaswini

## Description
This module provides two core data structures used in the Pixora
(Pinterest-style) console application:

| Structure | Purpose |
|---|---|
| **NotificationQueue** (FIFO Queue) | Handles activity notifications: new messages, pin saves, follows, comments. |
| **ChatList** (Doubly Linked List) | Stores chat messages and supports forward/backward navigation with per-message unread tracking. |
